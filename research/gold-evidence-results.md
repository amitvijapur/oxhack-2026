## Land-contract preparation

Every GeoJSON feature has a stable sample key and the source point in longitude,latitude order. The catalogue records original datum, reported GPS error scope, dates/precision, file hashes, lab methods and attribution terms. Original sample and laboratory IDs remain separate.

All 67 land-template rows are `not_evaluated`, with every contract field blank. Future joins must retain authoritative source/record IDs, geometry version/CRS/hash, snapshot/effective dates, the spatial predicate and uncertainty. Use point geometry and retain one-to-many relationships. A/B point bounds are not parcel boundaries, and point containment does not locate the upstream mineral source or establish rights.

## Verification

- Independent CSV/JSON audit checked all 67 normalized records and every original source field without importing the production parser. Counts, IDs, raw batches, assays, methods, retests, coordinates and source record references match.
- A/B are disjoint and cover the 67 selected -200 mesh locations exactly once. The 23 paired -80 mesh analyses remain in the source archive and are excluded from the primary packs.
- Independent review verified summaries/batch medians, catalogue/selection, publication precision, code provenance, all 24 non-validation pack file hashes and all empty land-contract fields.
- `python3 -m unittest discover -s tests -p 'test_gold_evidence.py' -v`: 12 passed against the actual pinned source; 12 also passed with no skips from the portable bundle. Tests cover input/output tampering, censored/null values, raw field preservation, geometry order and land-match unknowns.
- Both A and B regenerated byte-identically in a fresh temporary directory using only the portable handoff. Identical reruns returned unchanged. ZIP entry hashes and integrity checks passed.
- Source and method files are unchanged. The earlier copper extractor, tests, selection and handoff archives are preserved.

The source remains a targeted historical survey. It does not establish undrilled status, land availability, economic deposits or predictive accuracy. No model, MiroFish run, contract lookup, repository-policy change or merge was performed.
