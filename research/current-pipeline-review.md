# Current data, model and output connections

Reviewed against integrated main `57c6f320a8e0a5346643ab80c9e492b7cc4b2be0`
on 25 October 2026. This is a description of the current implementation, not a
proposal to change its mathematics.

## Connected now

- Pinned showcase bundles feed the globe, plots and Land/Ground/Market displays.
- The original 67 A/B sample features feed the canonical evidence screen through
  the Decision tab. Area A passes and Area B fails the current proposed screen.
- Explicit demo controls feed the shared `model/tok-option/workbench.mjs` engine.
  The same engine supplies local exports. Pending and real modes leave financial
  outputs unavailable.
- The engine maps hypothetical mineral economics to an assignment-value proxy,
  applies an eligible support-score adjustment directly to that proxy, then
  computes dated sale/no-sale cash, entry gates and constrained selection.
- Actual swarm runs feed diagnostics. Failed or incomplete checks prevent their
  use in monetary scenarios. Explicit synthetic demo imports can illustrate the
  intended arithmetic but do not establish predictive skill.
- Unsold marks remain separate from cash. Optional authenticated publication can
  store attributed engine outputs; it does not update live model controls.

## Disconnected or manual boundaries

1. Map selection only changes the displayed context or opens the Decision tab.
   It does not pass the selected plot, area, acreage, rights or terms into the
   workbench. The workbench has an independent Area A/B control. Land-list
   readiness currently calls the default Area A screen.
2. Live XAU quotes feed the header only. They do not change the model's price
   assumption. Historical gold CAGR is available through an explicit demo action.
3. Sentiment currently adjusts assignment value directly. There is no fitted
   sentiment-to-gold forecast or calibrated gold-to-parcel price relationship.
4. Claim records, surface sales and sediment assays provide context; they do not
   fill executable option terms, recoverable ounces, geological probability or
   sale hazard. These inputs are invented in demo mode and missing in real mode.
5. Leaving Decision unmounts its local controls and imported swarm state. Returning
   starts a new local workbench state. The town animation is a separate pilot.
6. The active Explorer does not consume the optional Convex bridge components.

## Verification

Ten saved traces were generated by importing the canonical engine with the actual
sample features. Eleven assertion groups check evidence count, null states,
cash arithmetic and probabilities. The 90-day flat demo returns USD7.60 expected
cash, a USD800 premium changes this to USD-142.40 and SKIP, Area B is SKIP despite
available hypothetical arithmetic, and actual news remains blocked. The explicit
synthetic fixture produces USD18.00172, a USD10.40172 difference from baseline.

The model's current wiring is suitable for reviewing hypothetical assignment
arithmetic. A complete parcel-specific predictive trading model still requires
the missing inputs and relationships above. No trading edge is established by
these execution checks.
