## The fee disclosure

The fixed-fee baseline has $69,230.77 assignment proceeds and $3,710.22 expected cash, giving 12.35% non-annualized return on $30,050. Still, 51.2% of 90-day paths do not sell and median cash is −$30,050. Unsold marks are separate from cash.

Hold the same contract and scale each invented reference fee by s. Each fee becomes $2,307.69; upfront is $32,307.69, expected cash is $350.77 and expected return is 1.085714%. The helper returns SKIP because upfront exceeds the $30,050 per-option limit. The apparent higher return in the fixed-fee case depends on that separate fee assumption, not measured investment skill.
